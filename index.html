About This Project

This is a demo frontend for a Deepfake Image Detector. The actual prediction is done by a separate backend AI model (for example, built with Python, TensorFlow, or PyTorch).

To use this in production, connect the frontend to your backend API endpoint in script.js. The backend should accept an image file and return JSON like: 

{
  "label": "deepfake",        // or "real"
  "confidence": 0.91
}
